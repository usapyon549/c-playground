# c-playground

C言語の基礎やデータ構造、メモリ管理などを実際にコードを書きながら学習・検証するためのリポジトリです。

完成度を重視したプロジェクトとは異なり、興味を持ったテーマやC言語の仕組みを小さく実装し、試行錯誤しながら理解を深めることを目的としています。

ポインタ、構造体、動的メモリ管理、データ構造など、C言語ならではの概念を中心に、実装と学習内容を記録していきます。
